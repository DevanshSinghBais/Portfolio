## 🌐 About the Project

Welcome to my digital space.

This is my personal developer portfolio, designed to go beyond a conventional website. It combines modern web technologies, interactive visuals, and a 3D-inspired experience to present my work, interests, and technical journey.

The goal is simple: **make exploring my work as engaging as building it.**

Whether it's developing AI-powered applications, experimenting with machine learning, or engineering software solutions, this portfolio brings my work together in one place.

* **Immersive Experience** — A visually engaging interface built around modern web design.
* **Interactive 3D Visuals** — Three.js-powered graphics and interactive elements.

## 🛠️ Run Locally

Want to explore the code or run the portfolio on your machine?

### Prerequisites

* [Node.js](https://nodejs.org/)
* npm
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/DevanshSinghBais/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Vite will display a local address in your terminal, usually:

```text
http://localhost:5173
```

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
