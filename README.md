## ✨ About the Project

This is my personal developer portfolio, designed to go beyond a conventional website.

Instead of presenting projects through a static collection of cards, the portfolio combines modern UI/UX, interactive animations, and 3D-inspired visuals to create a more engaging experience.

It brings together my work in AI/ML, large language models, computer vision, and software development in one place.

**The idea is simple: make exploring my work as engaging as building it.**

## 🚀 Features

* **Interactive 3D Experience** — Immersive visuals and graphics that bring the interface to life.
* **Dynamic Animations** — Motion-driven interactions that make navigation more engaging.
* **Modern UI/UX** — A carefully designed interface with a focus on visual hierarchy and usability.
* **Developer Showcase** — A central hub for my projects, technical skills, and interests.

## 💻 Run Locally

Want to explore the source code or run the portfolio on your machine?

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/DevanshSinghBais/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Vite will display a local development URL in your terminal, usually:

```text
http://localhost:5173
```

Open that address in your browser to explore the portfolio locally.

### Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
